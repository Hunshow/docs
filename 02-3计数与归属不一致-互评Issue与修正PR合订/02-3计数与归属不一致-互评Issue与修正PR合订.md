## 说明

先说结论：这篇 02-3 的骨架我是认同的——「四方收敛到同一个前提（可售库存没有可信定义），而非某个瓶颈」「33 条陈述 0 张单据，且这是现状结论而非调查疏漏」，这两条判断我都核对过，站得住。

下面的意见集中在**可逐条复核的表述层**，不涉及推翻核心结论。我对照的是仓库里的 `docs/discovery-report.md`、`docs/作业内容分析/01-2`、`02-2` 原文。

## 一、四处可直接改正的计数 / 归属不一致

| # | 位置 | 现文 | 核对结果 |
|---|---|---|---|
| 1 | §4.5 末段 + 结论 4 | 「按 retail-02 给的 **7 字段**台账模板填，**六个字段**里四个填不出来」 | 同一句里 7 与 6 冲突。§4.5 的表格共 7 行（名称 / 来源人 / 版本 / 样本时间窗 / 权限 / 已取得或待补 / 与陈述的差异），填得出的是前两项，填不出的是后五项。建议改为「**七个字段里五个填不出来**」，否则读者按表格数会得到与正文不同的结果。 |
| 2 | §4.1 标题「**三个数字**：全部无源记录」 | 表内实际出现 4 个数字（12%、48 天、8%、30%），只是把 8% 与 30% 并进了同一行 | §4.6 自己写的是「12%、48 天、8%、30% **四个值**」，两处口径不同；结论 5 又写「**三个数字**……12%（无分母）、8%、30% 三者」，这一处把 48 天整个漏掉了。三处对同一组数字用了「3 / 4 / 3」三种计数，且结论 5 的「三」少了一个。建议统一为「四个数字」，或在结论 5 说明为何把 48 天单列。 |
| 3 | §4.1 关键推论 | 「这正是**阶段 02-2 里必须做三因拆分**（真缺货 / 有货未上架 / 标识数据错）的原因」 | 三因拆分不是 02-2 提出的。02-2 全文（现状流程图与异常路径）只做了「起点断 / 输入断 / 交接断 / 判断断 / 末端断 / 旁路断」六断，没有拆因结构。三因拆分出自 `01-2-baseline-value-hypothesis.md`（M1a/b/c 及结论 3「拆因比水平重要」）。建议把指向改为 01-2，否则按图索骥的读者在 02-2 里找不到。 |
| 4 | `01-2` 第四章一句话 | 「上述 **6 个数字**里……**3 个**是目标值被误当基线（12%、48 天、5%/35 天）」 | 「6 个」与「3 个」互不自洽：括号里已列出 12%、48 天、5%、35% 四项；若把 5%/35% 当一项，则总数也不是 6。建议先定义一个明确的分组（例如「四个待测数值 + 一对目标值」），再让两处数字都等于它。 |

这四条都不影响结论，但都属于「读者照着数一遍就会得出不同答案」的类型，容易被当成疏忽，建议提交前统一。

## 二、一处需要你判断的表述冲突

**§3.4 D1 的【核对结论】写「冲突不成立，层级不同」，但结论 3 写「同一份 Brief 内部就有一处硬冲突」。**

- D1 的推理是：问题段「自动补货」是终态诉求，边界段「只读核对」是本阶段边界，两者是三个时间层，因此不是矛盾。
- 结论 3 的表述是：「同一份 Brief 内部就有一处**硬冲突**……必须写进问题清单并由顾明岚与傅景书面确认」；问题清单第 6 条也标成「retail-01 **内部冲突**」。

我理解你想表达的两件事其实是分开的：**逻辑上可以解释（层级不同），但风险上必须书面锁定（否则 6 周后被反噬）**。可是「冲突不成立」和「一处硬冲突」放在同一份文档的两个位置，读者会得到相反印象。

建议二选一的写法：

- 方案 A（我认为更准）：「**逻辑冲突可解释，但范围风险必须锁定**」——D1 保留层级分析，结论 3 改掉「硬冲突」这个词，直接说「本阶段范围排除项须书面确认」。
- 方案 B：「**保留为形式冲突**」——承认零售-01 文本本身有两处相反表述，只是可归因于时间层不同；那 D1 的「冲突不成立」就要改成「冲突成立但可归因」。

只要两处用同一套措辞，我这边没有别的意见。

## 三、三个问题

1. 第二节这处，你倾向方案 A 还是 B？如果选 A，我可以直接提一个只改措辞的 PR。
2. §4.1 标题到底以「三个」还是「四个」为准？8% 与 30% 合并成一行是有意为之（都属"执行侧自述"），还是排版结果？
3. §4.5 里「与陈述的差异」这一项，你写的是「无法填写——没有原始记录，就没有可比对象」。这项算「填不出」还是算「已填写为"不可比"」？这个判断会连带影响第一节第 1 条的最终数字。

## 刻意没改的三处

这三处都需要你判断，我不替你决定：

1. **D1 与结论 3 的措辞冲突**——`§3.4 D1` 写「冲突不成立，层级不同」，结论 3 写「同一份 Brief 内部就有一处硬冲突」。见 #1 问题 1，等你在方案 A / B 里选。

两种写法都成立，但选前者不会预先替第 2 个问题下结论：如果你认为 8% 与 30% 应合并为一行，标题就无需再改；如果认为应拆开，改成「四个数字」也只是改一个词。
